# 地图识别与下载修复（2026-10-04）

地图出现错误分支、更新后仍显示旧图、主图失效后无图的问题已复现并修复。修改仅在插件代码和测试中，没有清空线上资源缓存或重启机器人。

## 行为变化

- 同名肉鸽关卡不再默认取第一个关卡 ID。未指定分支时返回选择指令，例如 `ark肉鸽关卡 止变 界园 分支2`。分支编号按该期同名关卡的 ID 排序，与难度和紧急模式分开。
- 期名参与筛选；选定分支后，敌人数据和地图使用同一个 `level_id`。同名 Wiki 图片无法区分分支，因此选定分支使用该 ID 对应的 torappu 预览。
- `ark肉鸽敌人` 的关卡限定查询及关卡兜底查询复用同一选择逻辑；卡片上的后续查询说明保留分支编号。
- 唯一关卡仍优先使用 Wiki 图；链接下载返回空或抛出异常、最终无可用图片时，继续尝试 torappu。已有可用 Wiki 图片时不额外请求预览。
- 地图下载、批量资源下载、惰性图片读取统一以带 URL 哈希的文件名写入/优先读取，避免“新响应写旧文件名，读取却命中另一个旧文件”和新下载的同名文件串图。保留旧缓存的兼容读取。
- 关卡级“无地图”标记包含 `stage_id`，某个关卡缺图不会压住另一个同名同代号关卡的有效预览。
